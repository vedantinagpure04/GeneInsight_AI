GeneInsight AI 🧬

AI-Based Breast Cancer Gene Expression Analysis

About the Project

GeneInsight AI is a Python-based bioinformatics project designed to analyze breast cancer gene expression data and identify important genes using computational analysis.

Objective

To analyze gene expression patterns in breast cancer samples and generate useful insights through an interactive dashboard.

Dataset

- Dataset: GSE42568
- Source: NCBI Gene Expression Omnibus (GEO)
- Disease: Breast Cancer

Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Seaborn

Key Features

- Gene Identification
- Gene Annotation
- Gene Expression Analysis
- Gene Expression Heatmap
- Interactive Dashboard
- AI Research Summary
